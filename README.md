Peer-to-peer file transfer using WebRTC and SignalR. Direct device-to-device communication, no file storage.

Automated map viewer for Minecraft Java Realms. Downloads backups, renders interactive 2D maps, and deploys to GitHub Pages every 12 hours.

`TypeScript` &middot; `Node.js 22` &middot; `GitHub Actions` &middot; `GitHub Pages`

&rarr; [`adrianoreussavi.github.io/realms-map`](https://adrianoreussavi.github.io/realms-map)
